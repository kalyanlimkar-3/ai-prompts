You are working in the current repository.

Your task is repository discovery only.

DO NOT modify, create, delete, rename, or format any files.

Inspect the repository and determine:

1. The application type and technology stack.
2. The repository structure
3. The main application entry points.
4. Existing modules/components.
5. Existing APIs or services.
6. Existing data models or persistence mechanisms.
7. Existing tests and how they are executed.
8. Build and run commands.
9. Configuration files and environment variables.
10. Existing documentation.
11. Important architectural patterns already present.
12. Any constraints or conventions that future implementation agents should know.

Also identify anything that appears relevant to building a future Smart Fare Alert capability.

Do not infer implementation details that are not supported by the repository.

Clearly distinguish:

- facts discovered directly from the repository
- reasonable observations
- unknowns that require human clarification

Return a structured repository discovery report.

Do not make any changes to the repository.
